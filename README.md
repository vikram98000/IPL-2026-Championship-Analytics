# IPL 2026 Championship Analytics Dashboard

## Project Overview

This project analyzes the IPL 2026 season using ball-by-ball cricket data to understand team performance, player impact, venue trends, and the key factors behind RCB’s championship-winning campaign.

The project was built using Python, SQL, and Power BI with a focus on sports analytics, storytelling, and interactive dashboard development.

---

## Tech Stack

* Python (Pandas)
* SQL
* Power BI
* Excel

---

## Dashboard Pages

* Executive Summary
* RCB Championship Analysis
* Player Performance Analysis
* Venue Analysis
* Match Insights

---

## Key Insights

* RCB’s middle-over batting consistency played a major role in their title-winning campaign.
* Bowling discipline and dot-ball pressure were key differentiators.
* Death-over efficiency significantly impacted match outcomes.
* Venue conditions strongly influenced scoring patterns throughout the season.
